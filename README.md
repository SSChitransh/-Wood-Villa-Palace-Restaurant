## Before publishing
1. Replace the illustrative Unsplash photos with current photos supplied by the property. The current images communicate the design direction; they are not verified photos of this exact property.
2. Confirm the property name, phone, exact postal code/address pin, room categories, pricing, check-in/check-out, restaurant menu/timings, amenities and booking policy with the owner.
3. The provided Maps short link resolved to a different place title in the lookup, so this version uses a Google Maps search URL built from the published business name and address. Test the directions link and embedded map on a phone before launch.
4. Publish the folder on any static hosting service (Netlify, Vercel, GitHub Pages or a regular web host). No build process is required.
